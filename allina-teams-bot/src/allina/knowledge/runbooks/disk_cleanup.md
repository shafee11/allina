# ALLINA Approved Runbook: EC2 Disk-Space / Test-Log Cleanup

**Runbook ID:** `RB-A7-EC2-DISK-CLEANUP-001`  
**Version:** `1.0.0`  
**Scope:** ALLINA POC — A7 Remediation Agent  
**Risk Classification:** Tier 2 (Destructive cleanup; requires authorized human approval)  

---

## 1. Operational Objective

Safely recover disk space on an allowlisted EC2 test instance by removing expired, non-critical test log files generated by POC workloads.

---

## 2. Mandatory Boundary Constraints

Execution is restricted to the following server-side boundaries:

| Parameter | Constraint | Description |
|---|---|---|
| **Target EC2 Instance** | Must match `${ALLINA_EC2_INSTANCE_ID}` | Execution against any other instance is prohibited. |
| **Target Directory** | Must match `${ALLINA_ALLOWED_LOG_DIR}` | Canonical path (e.g. `/opt/allina/test-logs`). Subdirectory traversal (`../`) is prohibited. |
| **Allowed File Prefix** | Must match `${ALLINA_ALLOWED_LOG_PREFIX}` | Default prefix `allina-poc-`. |
| **Allowed Extension** | Must match `${ALLINA_ALLOWED_LOG_EXTENSION}` | Default extension `.log`. |
| **Minimum Age** | Must be $\ge$ `${ALLINA_MIN_FILE_AGE_HOURS}` | Files modified within the last 24 hours are strictly excluded. |
| **Maximum File Count** | Maximum `${ALLINA_MAX_CLEANUP_FILES}` | Safety ceiling (default 50 files per run). |
| **Maximum Recovery** | Maximum `${ALLINA_MAX_CLEANUP_BYTES}` | Safety ceiling (default 10 GB per run). |

---

## 3. Strict Exclusions (Default-Deny)

The following file types MUST NOT be targeted or deleted under any circumstances:
1. **Symlinks / Hardlinks:** Any file where `os.path.islink()` or `test -L` is true.
2. **System Logs:** Any path outside the allowlisted directory (e.g., `/var/log/*`, `/var/log/syslog`, `/var/log/messages`).
3. **Active Files:** Any file currently open by a running process (checked via `lsof` / `fuser` or open file handles).
4. **Non-POC Files:** Files not starting with the approved prefix (e.g., `application.log`, `server.log`, `config.json`).
5. **Fresh Files:** Files with modification timestamp newer than the minimum file age.

---

## 4. Pre-Execution Requirements

1. **SSM Online Check:** The target instance must report `Online` in AWS Systems Manager.
2. **Mount Point Verification:** Target log directory must reside on a valid filesystem mount point.
3. **Structured Plan & Hash:** A7 must produce an immutable `RemediationPlan` with an exact list of candidate files, sizes, and timestamps, bound by SHA-256 hash.
4. **Authorized Approval:** An authorized human approver (distinct from requester) must approve the plan hash.
5. **Dry-Run Default:** If `ALLINA_DRY_RUN=true` or `ALLINA_ENABLE_REAL_EXECUTION=false`, simulate only.

---

## 5. Execution & Verification Procedure

1. **Pre-check:** Measure disk space (`df -k`) on the target mount point.
2. **Atomic Verification:** Recheck file existence, path containment, and hash integrity immediately before execution.
3. **Execution:** Unlink or archive-and-delete only the exact allowlisted candidate files.
4. **Post-check:** Re-measure disk space (`df -k`).
5. **Success Criteria:**
   - All targeted candidate files are removed.
   - Available disk space on the mount point increased by approximately the estimated recovery bytes.
   - No errors or partial failures.
